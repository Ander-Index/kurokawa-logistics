# 面试记录

> [!quote]- A973EE90-8C90-4358-BF23-C777323F827C
> 
> “坐吧。”
> 
> [[ID.STAFF-1|石铠]]拉开椅子，待墨狡坐定后站在了他身后。
> 
> “您好，我是墨狡。虽然石铠可能提前和您打过招呼了，但是我认为我还是有必要向您重新进行自我介绍。”墨狡略显僵硬地站起来朝着面前鞠了躬。
> 
> “墨狡，目前 28 岁，就读于████大学电力方向博四，由于课题有些激进，所以毕业被学校审核卡了一年，现经由贵司石铠介绍来此面试。个人擅长的是电力研究与格斗，爱好也是这两方面。虽说我的研究能力没有石铠强，但在格斗这方面我还是敢说能压住石铠一头的。”
> 
> “叫我老黄就好。放轻松，紧张会降低你的表达效果。”
> 
> “嗯…我并没有紧张。我从很早之前就在各种渠道听到过龙珀的安保、研发和经济实力，也对贵司的研究和工作环境非常向往。从踏进龙珀的那一刻起，我就仿佛回到了自己的小家一样，很放松，也很快乐。我觉得我的能力在这里会得到更好地体现，所以我非常希望黄先生可以给我一个机会去实现我的价值，为龙珀…”
> 
> 
> 墨狡突然觉得脑子有点混乱，片刻后才回过神来，“为了龙珀…ㄉ…█……”
> 
> “石铠，”ROOT 接过石铠手上的文件，“正确率不错，你明白这些数据的含义吗。”
> 
> 墨狡并没有意识到自己刚刚的最后几个字，只觉得自己有些走神：“呃…不好意思。您说这些数据吗，我只能用我所学过的知识来帮石铠处理这些数据。只是…”墨狡思考了一会，“我不觉得这些数据是基于合理的现实实验所得出的数据，如果这些数据是正确的话，对现实科学将是一个巨大的冲击。您看，其中一部分给定数据的体积与质量有明显的错误，但其余辅助的错误参数却恰好解决了刚刚提到的问题，最终得出了一些看似正确但却很恐怖的数据与结论，这是我所不理解也不能接受的。”
> 
> 墨狡回过身去看向石铠，石铠只是立在那里，看着 ROOT 和他手中的那份数据，“我不觉得这是石铠的实验所得出的数据，他不会犯这种等级的错误的。这份数据大概是假设出来的，但数据过于脱离现实，所以结论不具有参考意义。”
> 
> “这里没你的事了。”ROOT 抬了下头，示意石铠离开。
> 
> “所以我是通过了吗？您放心，我一定会努力工作的，我真的非常热爱…”还没等说完，墨狡的身后传来了门上锁的声音。
> 
> “墨狡。”
> 
> 墨狡想要说什么，但大脑传出的信号却像是被卡在了某处完全张不开口，更恐怖的是，自己的身体也完全动不了。ROOT 缓缓起身，从背后托住了虎头的下巴，另一只手放在了虎头的后脑。
> 
> “这是给你作为入职管理组的礼物，石铠已经为你铺好了路，你会沉溺其中。”

# 批注

- 石铠虽然不需要进食人类食物，但是墨狡还是经常叫着他去食堂充电
- 据 ROOT 透露，耦合度加深后墨狡很喜欢躺在他的腿上一直睡到下午上班
- 据石铠透露，每次他都会提早五分钟去食堂多打包一份甜点留到晚上吃，如果没有的话他会延迟和自己的切磋专门去公司外到他自己珍藏的小店买一份面包，只是他口中的那个小店貌似经常不开门。只要看看带回来的是有着神秘包装的面包，还是公司对面店里普通包装的蛋糕，或者他的微表情就知道那个小店开没开门了。
