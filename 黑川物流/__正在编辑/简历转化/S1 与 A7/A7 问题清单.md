## 4. 龙髓植入：面试前已植入，但手术与控制阶段没有接起来【优先处理】

- 档案四明确说「我已经在他不知情的情况下给他植入了龙髓并且控制他了」，其时间是正式提出入职申请的前一日。因此面试中的放松、异常口号及「裸机」后的身体失控，可以发生在**已植入**的前提下，不能再直接判断为面试现场首次植入。
- 档案二 [[2F7E8654-5AE0-48D3-B668-6F2B87979669|石铠的测试与催眠记录]] 只写了宿舍催眠、入睡，未交代手术何时、在哪里、由谁完成，也未说明从这次催眠到档案四之间经历了多少次处理。
- 当前 [[龙髓#植入手术：枕下入路脑干直连术|龙髓植入流程]] 写有全麻、生命支持、切开及缝合等步骤；单凭在宿舍入睡或 ROOT 抚摸后脑，不足以完成该流程。若宿舍段只是诱导入睡的前置环节，可补出随后转入手术设施、完成植入及恢复的过程或记录。
- [[墨狡聊天记录总结]] 的聊天 A 曾说「不能秘密植入」，聊天 B 后续又允许睡眠中植入、以术后无感掩盖。旧清单把 A 的意见写成最终禁令，需撤回；但 B 的「无感」也不能替代当前正文要求的手术过程。
- 「体验版须先入职」来自较早讨论，不能不加区分地套到所有龙髓客户或这次植入。建议注明墨狡使用的是哪类植入方案，以及档案四提及的申请何时获批。
- 面试结尾的「入职管理组的礼物」应明确指正式洗脑、权限开通或耦合加深中的哪一步；若本意仍是首次植入，就与档案四的「已经植入」直接冲突。
- 「从踏进龙珀……很放松，也很快乐」本身可以是个人感受，也可以是已植入后的反馈，暂不作为独立矛盾。

## 5. 石铠的知情与操作授权【待解释特殊权限】

- 更明确的证据来自档案四：石铠知道龙髓植入与控制，提交过植入申请，并主动承认操控墨狡。不能只凭他参与面试，就推断他知道所有洗脑内幕。
- 聊天 B 总结把后门真相限定在 ROOT / ADMIN 知情层；石铠当前工号却是 STAFF-1。公司正文仅说 STAFF 不一定植入龙髓，并未完整写出这条信息壁垒，因此此处是**剧情与历史讨论的权限口径待统一**。
- STAFF-1 的特殊实验品身份可以解释例外，但「自己是受控实验品」并不自动赋予其控制他人的权限。
- 建议明确：他是经 ROOT 特批执行有限任务，还是只知道获准操作的部分功能；植入手术由谁实施，控制端由谁提供，权限能持续到哪个阶段。
- 档案四中 ROOT 对「控制？」表示疑惑，随后对话转向催眠。应区分 ROOT 是意外于秘密手术、越权控制，还是石铠的心理诱导方式，避免把「龙髓控制」与「普通催眠」混为一件事。

## 7. 「龙髓条目化修正记忆」的技术归属不清【优先统一口径】

- 正文「员工档案」开头直接写「该员工记忆已经由龙髓进行条目化处理并修正」，容易理解为龙髓可以直接读取、整理和改写记忆。
- 聊天总结的龙髓边界是不能读心、不能导出脑内数据、不能向大脑输出具体文字 / 图像等内容；现行 [[龙髓]] 主要描述运动与感官信号接口，没有列出条目化记忆编辑功能。
- 但 [[ID.STAFF-1]] 的现行报告又明确写了记忆擦除和注入实验，涉及**新版洗脑服从程序与记忆管理芯片**。因此不能简单判成「龙珀绝无记忆修改技术」，关键是不要把不同组件的能力自动归到普通龙髓上。
- 若墨狡也装有记忆管理芯片，应补出使用记录及权限；若只是通过催眠、感官反馈和梦境引导改变认知，建议将开头改为描述洗脑处理及记忆认知变化，避免承诺直接按条目读写记忆。
- 如果当前世界观已扩展了龙髓本身的能力，应同步说明新的能力边界，再统一 A7 与旧聊天总结的口径。

## 8. 档案一没有标明梦境范围和真正醒来的位置【优先处理】

- [[610A150D-0A45-4302-ACBB-73B3669C2947]] 从面试后的白色房间，切到「父亲」、合同、公司参观、运送任务、石铠重伤，再回到 ROOT 办公室；全文没有明确说明哪些段落仍在梦中。
- 聊天 B 总结说档案一是 ROOT 让墨狡放松后、墨狡**自身产生的梦**。若整篇都属于梦境，应在档案标题或开头注明，并给出梦境结束 / 现实恢复的边界；正文第三人称转为第一人称也可借此交代。
- 在梦境边界未明确前，「今后我们就是平级的同事了」不能直接拿来认定 ADMIN-7 与 STAFF-1 现实权限相同；「石铠重伤」「老牌员工」「本科毕业后连考两年」也不能直接当作现实履历冲突。
- 若合同签署、入职参观或运送任务中有一部分确实发生在现实，则须分段标注时间及真实性，分别解释平级称谓与角色经历。
- 还需区分「感官刺激诱发自身的梦」和「控制端直接写入指定梦境剧情」。父亲的形象、广告画面、完整对白若由龙髓直接灌入，就涉及第 7 项的能力边界；若是梦者自己的联想，则不构成该冲突。
- 聊天总结提到 ROOT 借梦境信息深化处理，但当前附档并未写他如何获知梦境内容。若后续确实用到这些信息，需交代口述、观察推断或其他设备来源，避免默认为龙髓能读梦。作者直接描写角色梦境本身不等于设备读心。

## 9. 面试中受话人与回答者错位【文字歧义】

- ROOT 接过文件后说「石铠……正确率不错，你明白这些数据的含义吗」，随后却是墨狡回答「您说这些数据吗」，石铠没有回答。
- 若这句话是问墨狡，应改称呼；若 ROOT 先叫石铠、再转问墨狡，补出转向或指示；若墨狡插话，则明确写成插话。

## 10. 实验数据的性质与求职动机可以补强【非硬冲突】

- 档案四交代 ROOT 修改了基础给定数据，面试时墨狡判断数据脱离现实、结论没有参考意义；这可以是用于筛选人才的测试题，并不必然代表龙珀真实实验出错。
- 但正文未说明 ROOT 的「正确率不错」评价的是计算过程、找错能力，还是对异常技术的理解。墨狡认为结论不可信，与其算题正确也不必矛盾，建议把评判目的说清。
- 聊天 B 总结把先进实验数据写成墨狡主动求职的动机，档案二则已写他原本就想进龙珀。两者可以同时成立；若采用「数据吸引他入职」这条主线，应区分此前看到的真实成果与 ROOT 临时改出的测试数据，避免读成他正因一份自己认为没有参考意义的数据而求职。

## 11. 日程便笺的机密内容如何被普通职员取得【待确认叙事意图】
