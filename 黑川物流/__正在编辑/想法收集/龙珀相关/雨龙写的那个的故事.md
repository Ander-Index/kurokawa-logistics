# 全包机械结构与空间压缩

> 更新日期：2026-10-20。原稿对“小手办能否连内容物一起压缩”的疑问，现已确认可行。故事本身的处理另审，本稿只整理能力与阵营差异。

## 一、已确认的思路

全包、密闭的机械结构可以视作一个舱：将其包裹范围内的内容物一并进行空间压缩，因此“连同内部一起缩成小手办”的设想成立。

这属于**空间科技**，空间压缩与黑胶的相关能力同源。它不是单纯把外壳缩小、强行挤压舱内物体。具体装置与压缩尺度仍待故事需要时展开。

## 二、不同阵营的掌握程度

| 对象 | 当前能力范围 |
| --- | --- |
| 龙珀 | 对空间科技掌握较多，能够通过技术较容易地复现包裹其他物体并进行空间压缩的效果。 |
| 黑川的隔代胶兽 | 只能对自己使用，不能像龙珀一样把其他东西包裹后进行空间压缩。 |
| AZ | 可以作用于装进自己身体内部的内容物；不据此扩大成能任意压缩体外物体。 |
