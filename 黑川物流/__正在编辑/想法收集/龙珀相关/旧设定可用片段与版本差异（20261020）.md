## 一、雨龙《龙珀发展史》：还能用什么

这份稿件早于龙珀形成正式设定，不能继续作为公司的完整发展史。正式公司介绍按本轮“普罗德安保起家，收入支持赫提研究”的方向重写；旧稿仅保留以下抽象思路。

| 旧稿片段 | 仍可用的部分 | 使用边界 |
| --- | --- | --- |
| L3、7：机械构造、能量传输、神经信号解析 | 可作为龙珀研究方向的概括，联系现行空间衍生机械技术、龙鳞接口与龙髓。 | 不再据此声称龙珀只有机械遗产、完全没有活性胶；赫提与胶原分化已另有口径。 |
| L8–9：人机界面兼容性问题 | 研发需要处理机械与肉体的兼容性，龙鳞与龙髓正是对应环节。 | 早期原型曾否造成文中列出的具体伤害，尚未确定；不保留为所有现行用户的必然代价。 |
| L13–14：工程优化、材料与信号处理 | 可作为研发逐步成熟的方向。 | 不恢复“星链”旧产品名，不自行增加具体替代材料、产品世代或上市顺序。 |
| L22–24：安保与外骨骼 | 与安保起家、外骨骼及高端义肢业务相容。 | 不照搬原文对所有使用者必然造成关节、脊柱损伤的结论。 |
| L28：巡逻机器人、自主防御平台 | 可留作安保产品构想。 | 是否已有具体产品、能力与故障模式另审，不直接写成完整公开产品线。 |

### 已淘汰，不再迁入现行条目

- **L3、8、20、32：永久缺少“活性胶粘合剂”，形成无法突破的终极瓶颈。**现行龙珀拥有来自赫提的龙鳞；增殖、繁殖或同化需要苛刻条件，但条件未定，不等于用一点永久少一点。
- **L15、24、26、28、30：普遍慢性损伤、药物依赖、必然过热或能量场暴露等成套代价。**缺少现行设定支持，不把这份旧稿的具体故障与医学描述继续当成事实。
- **L14：“星链”作为正式产品名。**不恢复。
- **L19、32：从个人到城市级的完整业务规模与全领域巅峰地位。**不因旧稿出现就视为已定；公司简介采用已确认业务即可。

## 二、六月讨论与现行口径的区别

来源：[[墨狡与石铠的设定讨论记录]]。原文同时包含多个阶段的协商、作者构想与后来归档结论；下表区分已经更替的规则、仍待审的个案与可以保留的候选。

| 原记录位置 | 原说法或问题 | 本轮处理／现行口径 | 状态 |
| --- | --- | --- | --- |
| L36、42 | 龙髓位于脖颈，非脑内。 | 按最近两天的脑部植入、信号中间人口径修订；不把旧位置作为并存方案。具体手术写法另行整理。 | 旧定义失效 |
| L37、42、55、62 | 龙髓无对外传输，只接收外部控制信号。 | 龙髓可与赫提通信，传感数据供行为推测使用。触感仍由本地链路解析，不依赖赫提生成。协议和实现细节尚未定。 | 旧全面禁令失效 |
| L31、42、62 | 胶衣接口、反向触感与身体控制。 | 思路可沿用；明确为液压传感义肢 → 龙鳞 → 龙髓 → 大脑，义肢连接部位皮肤及神经需胶化。 | 机制更新 |
| L36、43，对照 L56、62 | 前段说不能秘密植入，后段又用睡眠中无感植入补剧情。 | 龙髓仍需手术；不能把睡眠无感直接写成无需手术。墨狡当时具体知情程度与经历应结合档案另审，不在此改故事。 | 个案待审 |
| L34、76 | 同一时间一个人格生效；另有自主设定意识、潜意识植入的构想。 | 龙髓基础功能不生成第二人格、不写入思想。通过信号、动作及反馈塑造倾向可以保留；不把作者当时的意识植入比喻当成标准能力。 | 收窄机制 |
| L44、64 | ADMIN 安装龙髓且记忆可能被篡改以忠于龙珀。 | 直接记忆管理归内部实验扩展“龙髓 DLC”，不属于标准龙髓；相关研究不稳定。石铠、昱江及 ADMIN 的具体表现单列审阅。 | 模块与个案待审 |
| L55、63 | 开源、免账号、近场调试 APP，用于掩护后门及筛查目标。 | 可作为尚未确认的产品／剧情方案。赫提 AI 网络、定制门禁配对的存在，不自动证明这套 APP 已有正式产品。 | 可用但未定 |
| L45 | 龙髓远程控制属于机密。 | 具体控制后门的知情范围，不能直接推成全部空间科技或全部产品的公开范围。空间科技公开到什么程度仍待定。 | 保留问题，勿扩大 |
| L23、35、56、64 | a1 与赫提在早期记录中容易被当成不同角色，后文赫提固定为 STAFF-0。 | a1 即旧 ADMIN-1 赫提，现为 STAFF-0／s0，也是古代智慧体。权限变更不代表换了个体。 | 身份已澄清 |

### 可保留、但尚不能据此宣告落地的部分

- **调试 APP 的伪装与用户筛查**（L55、63）：作为产品或情节候选保留，具体使用方式另审。
- **身体先行动、大脑逐渐合理化的表达**（L55、62、76–77）：可用于描写长期行为塑造；不能借此追加直接思想写入、完整梦境脚本或必定成功的心理机制。
- **远程控制的信息壁垒**（L45、64）：属于审阅具体角色知情范围时可参考的旧讨论；不在此扩大或重排现行权限体系。
