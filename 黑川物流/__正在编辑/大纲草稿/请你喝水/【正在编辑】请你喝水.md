## 二、硬设定（撰写时不可违背）

1. **催眠 ≠ 放松，催眠 = 精神高度集中。**（看电影类比：被完全吸引、不在意干扰的那一刻，就是被催眠。）
2. **手法：紧绷—断弦。** 在对方情绪极端紧绷、高度防备时，突然制造巨响（如摔灯泡），思维产生瞬间空白；精神暴起又立刻发现没有异常 → 注意力松弛并集中回部长身上 → 趁隙植入暗示。
3. **记忆锚点：数字「0」。** 倒计时让人本能集中注意力，适合做锚。
4. **入职分两次完成。** 立即入职对身心伤害太大：第一次只种锚，借口"材料不齐"请其明天再来；第二次上门才完成调教与收编。
5. **排异反应**：第一次当夜高烧、头痛（免疫反应开始）；次日请假后不适感消失，却莫名觉得"今天去黑川会有意外发现"。
6. **收尾意象**：他正常回到警队上班，一切如常——只是黑川集团永远欢迎他回家。

## 三、章节大纲

> 采用原草稿的四个章节标题。各章节拍供撰写时参考，可调。

### 第一章 · 突击检查

- [ ] **由头**：有"其他力量"找茬举报，警方派龙井茶走访调查黑川物流。
  - （参考事由：大型物流外包招标中涉嫌使用虚假证件骗取保证金、壳公司虚假开票偷税漏税——合同均由市场部签署盖章，故由市场部部长接待，理由充分。）
- [ ] **洛书视角**（可穿插）：突然上门一个警察来找麻烦 → 立即找人事部查这个人。
- [ ] **对峙**：龙井茶全程戒备——自带水、不寒暄、不坐真皮沙发。
  - "不了，我不喝。"
  - "少跟我打马虎眼，有证没有？"
- [ ] **杀气**：空气中浓烈的火药味。龙井茶感到强烈的"杀"却找不到来源；神经紧绷，死死盯住洛书，确信凭自己身手随时能制服对方。
- [ ] **断弦**：部长人畜无害地坐在那里，"你看起来很劳累的样子"，越凑越近——突然"啪"的一声巨响！思维空白，催眠，种下锚。
- [ ] **收尾**：部长借口材料不齐整，"希望您明天再来一下。"龙井茶头疼欲裂，冷脸告辞，拒绝接送。

### 第二章 · 反查身份

- [ ] 黑川方连夜反查龙井茶底细（呼应洛书"立即找人事部查这个人"）。
- [ ] 确认其正直人设与价值 → 上报，No.2 层面过目。
- [ ] 布置第二天的局：全体员工知情配合，"胶兽们认得出他身体里的锚"。
- [ ] （本章可短，是暴风雨前的安静。）

### 第三章 · 二次检查

- [ ] **清晨**：高烧、体温极高，皮肤下隐见黑色脉动（胶兽化开始）。责任感驱使他第一时间打电话请假，谎称急性肺炎。
- [ ] **指令发作**：挂掉电话后，锚开始生效——"那个证件的公章有问题，我必须回去再确认一次。"职业病与正直感完美掩盖了被操控的事实。
- [ ] **便装潜入**：拖着摇摇欲坠的身体，再次推开黑川物流的大门。只觉得公司变得越来越亲切。
- [ ] **同调**：询问员工"这里是否有压迫"，员工出奇地一致；被挽留、被共鸣同调，被引导向内部。
- [ ] **动摇**：突然共鸣，想要逃跑——但是又不想逃跑了。
- [ ] **收编**：No.2 出场收走龙井茶。中意他的胆识与魄力，认真培养。"对付这样的人必须要稳着来，切莫打草惊蛇。"

### 第四章 · 催眠

- [ ] **认知翻转**："哦！原来我已经变成了胶兽，已经不再是人类了。"心甘情愿地入职。
- [ ] **初次介入**：看到那个孤独的背影（AZ），问了 AZ 一个问题。（⚠️ 问题内容待定）
- [ ] **结局**：回到警队正常上班，一切如旧——黑川集团永远欢迎他回家。他成为警务系统中的"针"。
