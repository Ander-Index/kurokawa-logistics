# ADMIN 组别的忠诚话语

ADMIN 组别说的不是「效忠龙珀」，而是「为了龙珀帝国」。

但「龙珀帝国」这个设定要藏一藏，降低出现频率，所以正文只写碎片化版本：

> “为了……龙……珀……”

偶尔在碎片之后带一个注音，只起「帝国」一词的头、点到即止：

> “为了……龙……珀……<ruby>ㄉ<rt>ㄉㄧˋ</rt></ruby>”

# 写法要点

- 碎片化：逐字断开，省略号制造被控制、被拖慢的语感
- 注音版偶尔为之（全库低频出现），用 [[特殊字符#注音标记]] 的 `<ruby>` 写法，只写起头（如 ㄉ），不写全词
- 场景较随意、不需要排版仪式感时，也可以直接在碎片后跟字符：`“为了……龙……珀……ㄉ”`
- 「效忠龙珀」这类旧说法不再由 ADMIN 组别使用（历史文本如需统一，另行替换）
