# 基础规则

库内大部分内容是简体中文，所以使用中文弯引号 “”‘’（外层 “”，内层 ‘’）。

西语（英语等西方语言）使用直引号 ""''（外层 ""，内层 ''）。

# 特别风格化

说话人属于东亚文化圈时，使用直角引号 「」『』（外层 「」，内层 『』）：

- 民国时期的中国
- 日本

**韩国不使用直角引号**——韩语标准引号是 큰따옴표 “”、작은따옴표 ‘’，字形与中文弯引号相同，按基础规则使用 “”‘’ 即可。
