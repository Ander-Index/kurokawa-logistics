# log

系统输出、测试报告、验证记录等"机器打印"内容，代码围栏标记为 `log`（Prism 官方 Log file 语法，阅读模式与 Publish 站点均可高亮；本地实时编辑视图不高亮属正常）。

Prism 的 log 语法会高亮以下元素：

| 元素 | 规则 | 示例 |
|---|---|---|
| 日志级别 | 整词匹配，分五档颜色 | `INFO` `NOTICE` `WARN` `ERROR` `FATAL` `DEBUG` `TRACE` |
| key | 小写字母/下划线开头 + 冒号（中文 key 不会高亮 key 本身） | `result: 8/10` |
| 字符串 | 双引号或单引号 | `"龙珀"` |
| UUID | 8-4-4-4-12 位十六进制 | `610A150D-0A45-4302-ACBB-73B3669C2947` |
| 日期 / 时间 | `2026-09-29`、`16:56:31` | 自动识别 |
| 数字 | 整数、小数、百分比、`0x` 开头 | `8.9` `20%` |
| 布尔 | `true` `false` `null` | 自动识别 |
| 分隔线 | 3 个及以上的 `-` 或 `=`（与库内 32 短杠约定一致） | `--------------------------------` |
| IP / MAC / 域名 / 邮箱 / 文件路径 | 标准格式 | `192.168.7.1` |

写法约定：

- **字段名保留原文**（如「力量」「成功率」），可以用空格对齐成表格式；不要求英文 key
- 想让某个字段的 key 也上色时，才用小写英文 key + 冒号（可选）
- 关键结论行用级别标签强调：`[INFO]`（过程）`[NOTICE]`（结果）`[WARN]`（警告/异常）
- 字段值里的中文概念可以加引号获得字符串高亮：`目标对催眠: "毫无了解"`
- 数字、百分比、箭头（operator）不依赖 key 也会高亮
- 继续沿用 32 短杠作为报告内分隔（同时触发 separator 高亮）
- 涉及档案编号时直接写大写 UUID，自动高亮
- 命令行保留 `$` 提示符写法

~~~log
$ combat_test --tester="石铠" --target="墨狡" --item="战斗能力"
--------------------------------
[INFO] 第一测试: "战斗能力"
[NOTICE] 测试综合评定: 8/10（人类）
  速/精度    : 8.9
  力量       : 7.1
  临场战术   : 9.4
  耐力       : 6.5
[WARN] 预估改造后评定: 9.5+/10（轻度机械化）
--------------------------------
[INFO] 报告完毕
~~~

# Prism 支持的其他语法

阅读模式与 Publish 站点的代码围栏高亮由 Prism 驱动，目前支持 297 种语言（[完整列表](https://prismjs.com/index.html)）。对设定写作最有用的筛选：

| 用途 | 标签 | 高亮内容 |
|---|---|---|
| 完整终端会话 | `shell-session`（别名 `sh-session`） | `$` 命令与输出分开上色 |
| 命令行脚本 | `bash` `powershell` `batch` | 命令、flag、管道、变量 |
| 错误堆栈 | `javastacktrace` | `at xxx.xxx` 报错格式 |
| 底层机械语言 | `armasm` `nasm` | 汇编 |
| 配置文件 | `ini` | `[区块]` + `key=value` |
| 结构化数据 | `yaml` `toml` `json` `properties` `csv` | 键值、字符串、数字 |
| 网络报文 | `http` | 请求行、Header、状态码 |
| 流程图 | `mermaid` | 流程/状态图语法 |
| 修改对比 | `diff` | `+` / `-` 行（记忆修改前后） |
| 版本历史 | `git` | 提交记录格式 |
| 失控代码 | `brainfuck` | 纯风格化彩蛋 |

提示：语言常有别名（`bash`=`sh`=`shell`，`yaml`=`yml`）；写了不存在的标签不会高亮也不会报错。冷门语法本地编辑视图与发布站表现可能不一致，以发布站为准。
