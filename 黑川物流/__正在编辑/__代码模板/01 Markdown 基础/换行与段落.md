# 标准换行（分段）

在开启“严格换行”的选项下

行与行之间必须空一行才能触发段落。

这样可以在任何地方都看起来统一。

# 紧凑换行（不分段）

但如果某个段落需要紧凑，不需要分段，只需要换行的话，  
那么只需要在上一个行的末尾加两个空格，然后再按下回车。  
就可以实现统一段落内的换行了。

# `<br>` 手动换行（不分段）

当然，你也可以在一行中 `<br>`（不含两侧的单引号）来换行，写几个就换几次<br><br>这样的好处是视觉上虽然分了段，但是实际上内容不会分段<br><br>这样就可以方便的进行脚锚，然后在别处直接引用这一段落。 ^Summary

# 中西文间距（盘古之白）

西文（字母、数字）与中文之间留一个半角空格：

- `叫我 ROOT 就好`、`就读于 X 大学`、`作为 ADMIN 的入职礼物`
- 数字与中文单位之间同样处理：`目前 28 岁`

代码围栏内的终端报文（log / KKN）属于风格化排版，不套用此规则。
