# 关于“大脑”的古卡玛特语

古卡玛特人不仅有“大脑”的专有名词，而且他们留下了**整个人类历史上关于“大脑”的最早文字记录**。

- **ꜣys（拟音：Ays / 艾斯）**
    
    - **圣书体拼写**：通常由表示秃鹫（𓄿）、芦苇（𓇋）、折叠的布（𓋴）等表音符号，加上表示人体组织的“肉块”限定符号（𓄹）组成。
        
    - **医学史上的奇迹**：在著名的《埃德温·史密斯纸草文稿》（Edwin Smith Papyrus，写于约公元前 1700 年，但内容据信抄自公元前 3000 年左右的古本）中，_ꜣys_ 这个词出现了 7 次。这也是“大脑”一词在人类文献中的首次亮相。
        
    - **惊人的解剖学观察**：在这份古老的外科文献中，一位古卡玛特军医记录了一个头骨破裂的伤员。他在检查伤口时，看到了露出的“大脑”，并形容其表面“就像熔化的铜冷却后产生的波纹状皱褶”——这被公认是人类对“脑沟”和“脑回”的最早描述。他还提到，手指触摸那里时能感觉到“跳动”（脑搏动）。
        

**一个有趣的文化反差** 尽管古卡玛特的外科医生对大脑有过如此细致的科学观察，但在古卡玛特主流的宗教和世俗观念中，“心脏”（jb）才是灵魂、思想和记忆的绝对中心。因此，在制作木乃伊时，法老的心脏会被精心防腐并留在体内，而“大脑”则被视为无足轻重的器官，防腐师通常会用金属钩从死者鼻腔探入，将其捣碎抽出并直接丢弃。

在古卡玛特语中，关于“心脏”不仅有专门的词汇，而且为了区分心脏的不同属性，他们使用了**两个**不同的词汇。这反映了古卡玛特人对心脏极高的重视程度。

这两个词分别代表了心脏的“精神属性”和“物理属性”：

# 1. jb（拟音：Ib / 伊布）—— 精神与灵魂的心脏

- **圣书体**：𓄣 （这是一个非常具象的符号，画的就是一颗带有血管的心脏）。
    
- **含义**：_jb_ 是古卡玛特文化中最核心的概念之一。它指代的是**思想、情感、记忆、智慧和灵魂的中心**。古卡玛特人认为，人所有的所思所想、性格和良知都储存在 _jb_ 里（也就是我们现代人认为“大脑”所负责的功能）。
    
- **神话意义**：在著名的古卡玛特死后审判（称量心脏仪式）中，被放在天平上与代表真理的“玛特之羽”进行称重的就是 _jb_。如果 _jb_ 因为生前作恶而变得沉重，死者的灵魂就会被怪物吞噬；如果重量等同于羽毛，就能进入永生。
    

# 2. ḥꜣty（拟音：Haty / 哈提）—— 肉体与跳动的心脏

- **圣书体**：通常包含前部（𓄂）和心脏（𓄣）的符号组合。 
    
- **含义**：这个词字面上的意思是“在最前面的（器官）”，它更多指代的是**胸腔里那个物理意义上、正在跳动的肉体器官**。
    
- **医学意义**：在古卡玛特的医学文献（如刚才提到的《埃德温·史密斯纸草文稿》和《埃伯斯纸草文稿》）中，当医生描述心脏跳动、血管网络（mtw）与心脏的连接，或者心脏的物理疾病时，通常使用的就是 _ḥꜣty_。
    

**总结一下它们在木乃伊制作中的体现：** 当防腐师处理遗体时，他们非常小心地把肉体的心脏（ḥꜣty）**留在胸腔内（或者取出防腐后再放回原位），并常常在心脏位置放置一个“心形圣甲虫”护身符。他们这么做，是为了确保死者在阴间的法庭上，能够拥有完好无损的**灵魂之心（jb）去接受最终的审判。
