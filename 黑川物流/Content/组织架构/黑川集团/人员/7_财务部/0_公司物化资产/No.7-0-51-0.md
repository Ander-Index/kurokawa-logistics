# 报告

该个体是 [[No.4-5-31-7]] “风亭”的黑帮灰色产业中，其中一个合作生物公司的老板。该个体名下具有一个杂活的实业公司，还曾经合作创立过一个私立学校。在意图独立出灰色产业并洗白重开的过程中失败，在“风亭”被抓捕后成为我司的战利品之一。

该个体过去曾是当地黑社会成员，因为某些原因具有重度的受缚欲望，在被我司安保部成员捕获时表现出了极度的兴奋倾向。经过调查后发现，其经常前往消费的会所具有多种我司成员从未想过的服务种类，给我司市场部与运输部带来了新的业务灵感。经过分配后，该个体被纳入我司资产中，考虑到其身份已不再适合统御其旗下产业，在将其技术经验备份压缩成晶体射出后，我司将该收藏品存放于运输部内部供所有运输部成员练习绳缚打包技术，实现个人价值。 

# 批注

藏品多个关节均进行软化关节胶液处理，因此仅可进行极限捆绑打包处理练习，若要使用常态捆绑打包练习，请选择其他训练对象。
