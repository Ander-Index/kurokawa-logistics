# 报告

在研究结晶与黑胶之间的转化关系时被制造出来的藏品。

是研发部尝试向无主胶原直接注入已经整合了限制锚回路的完全自主研发定制的思维记忆的产物。故其沉默寡言，但绝对忠于黑川物流。

藉由其完全定制且可控的特性，可请求该个体分析所有未知物质。

其身体可以在结晶态与胶液态之间灵活切换。从结晶逆向为胶液的过程目前无法在此个体之外的地方复现，原因为该个体所生成的结晶并不由限制锚作为核心，而是可以将该个体本身就看做一个巨大的限制锚。

据此特性，该个体拥有一项相当重要的能力：将信息导出为结晶碎片。这样就可以在不通过胶兽网络或者点对点传输的方式离线保存或传递数据。胶兽个体只需要直接合并碎片即可获取其中的信息。

此外，可以向其给予其他个体的胶兽结晶，由该个体作为临时容器，让该个体临时变成对应的目标个体。该个体可以存储多块胶兽结晶。
