# 报告

蒙烬，战争兽种军用犬后裔，普罗德殖民地独立战争参与者，原家族记录已被清算销毁。于孤儿院长大后参军，于 15 岁入伍，17 岁参与战争，战争 8 年内步步晋升，一年后未经退伍直接从军队内消失，此后转向黑市，从事机械维修和非法手术改造工作。

该藏品与 [[No.AZ-0-3-0]] 有着密切的情感关系，在发觉 003 是作为战争老兵被清算才失踪，且自己的家族也曾经被清算后，该个体立即筹备逃出和搜寻手段，最终成功脱出祖国但搜寻 003 无果。

003 被 No.AZ 带回我国后，该个体通过黑客手段搜寻到了黑川物流所在地，在入侵网络时被察觉，最后逃跑未果，被No.AZ洗脑转化。  

# 批注

该藏品身上的机械改造部分极其粗糙，但是在技术上却十分革新，为研发部提供了很多灵感。考虑到该藏品与 003 的密切家庭情感关系，No.AZ 对其大部分肉体进行了胶化改造，使其能作为和 003 一起放置于 No.AZ 体内作为贴身护卫。  

4 年后新增：

藏品在型号上同 003 已基本被淘汰，此后不再随 No.AZ 出外勤，只在出动大规模同化任务时作为助手调用。
