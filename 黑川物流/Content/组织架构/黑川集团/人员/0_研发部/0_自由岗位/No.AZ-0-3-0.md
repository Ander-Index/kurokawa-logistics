# 报告

墨泽，[[普罗德合众国|普罗德]]殖民地独立战争参与者，于16岁入伍，18岁参与战争，作为进攻方在普罗德宣布独立后战败，作为失踪者被登记在案。

该个体的右眼曾遭受贯通伤害，导致该个体失去了大约 10 年的记忆，且难以辨认他人面孔，对于精神暗示的抵抗能力大大下降。该个体在普罗德共和国游荡生存多年，有着丰富的徒手战斗经验和战斗直觉。在他的国家发布失踪名单时，该个体被当地混乱社会组织绑架并囚禁，因此错过了回国的机会，被登记在失踪名单中默认死亡。No.AZ 解救并将该个体作为早期洗脑协议的实验品，通过对其受伤的大脑施加胶液同化并比对，成功研究出了限制锚的雏形。

为表彰该藏品做出的贡献，我司赋予其优先享受肉体改良技术的权限，考虑到无所事事会导致该藏品因为无法实现自我价值而出现精神萎靡，我司针对其容易被催眠修改意识的特性，赋予其充当新人员工的催眠洗脑技能的教具的职能。

# 批注

在对该藏品进行催眠练习时，员工必须提交申请并准备撰写工作流程，由上级评估危险性后才可通过。

洗脑技能是转化子嗣必备的技术，请想要子嗣的藏品多加练习。
