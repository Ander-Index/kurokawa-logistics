# 报告

该个体在国外不法组织对贫民的压迫活动中，因其特别的外貌被我司员工发现，经过上级演算后，判定为具有一定研究价值的个体，经过安抚和诱导后成功捕获，于发现起的第15天后打包跨海运送至本部。

根据该个体称述，它因为当地土豪为“感兴趣”而向非法组织投资，成为被绑架的受害者之一。该非法组织致力于制造不同原种族的杂交而产出的稀有品，并且在该个体身上进行实验，植入了部分不知名混合的晶状类突刺测试过敏机制，在经过特殊原因（经调查发现为当地军阀内斗，投资者被枪杀，失去资金来源）逃出实验室后，在多个灰色地带进行求生，一段时间后被我司员工发现带回。

该个体由于缺乏正确价值观引导，在道德和心理测试中均不及格，对外人有极高的戒备，同理心缺失且存在心理阴影。

该个体在体检中，发现其为异卵双胞胎，但是在胚胎期间就吞噬了其兄弟。经过会议决定，在保留其身上实验痕迹的同时，只对他的基因进行适配而不对体内的兄弟进行适配，在此基础上进行胶兽转化实验，观测结果如下：

该个体的肉体正确进行了黑胶同化并成功植入限制锚，但是限制锚只能限制体内部分黑胶，无法被限制猫控制的区域（猜测为吞噬长大的兄弟细胞）开始出现执行体化程序才存在的仅神经黑胶同化，并通过执行体网络上传了执行体协议。该个体成为藏品和执行体的重合态，其人格和记忆都有一部分被洗脑格式化，但是仍然存在部分人性。

该个体身上的植入性突刺犄角得到了减轻痛苦的兼容，转化为银色胶原储存在内部骨骼中，该个体展现出优秀的控制金属银色胶原的资质，可控制犄角凸起在身上进行任意转移释放，暂且不明是天赋还是出生方式导致的肉体差异。

# 批注

该个体的心理问题需要长期引导治疗，请安排价值观健康，阳光向上且富有耐心的员工进行治疗。

该复合型员工同时存在“人性”和“直接被指令操控”的特质，经讨论后得出的结果是——该员工的存在形式更像是国家政府中训练调教出的“军人”，该员工对财务部的战争科具有重大意义，请严加看管或进行封冻保存。
