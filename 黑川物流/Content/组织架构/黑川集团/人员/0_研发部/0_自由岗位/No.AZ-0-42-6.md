# 报告

大学实习来黑川集团工作的数学系学生。黑川集团看中了其在人类中相对优异的数学天赋，将其在研发部内部入职。

入职后的方程式在研发部负责提供统一计算，与财务部脑机超算进行对接。对数据进行筛选统计。

由于其在入职之后就对自己的胶兽身体产生了非常大的迷恋，有时甚至直接在自己的人类肉体上做实验。如发现此行为，应当立即被限制或终止以严格控制此藏品的胶化速率。
