# 报告

罗穆尔，原陆军部队退伍成员，被编外成员古斯塔夫邀请前去德怀恩家族的金融集团当安保成员，在古斯塔夫教育子代时目击其转化教育行为，主动接触 [[No.8-4-42-T]] 时，被古斯塔夫捕获。经过简单调教后，送往我司作为实验体进行使用。

该实验体经过了战斗模拟-同化肉体抵抗-强制洗脑抗性测试后，清空其受调教记忆，并投入到 对军人特化限制锚 的制造测试中。在第 XXX 次实验后，终于研究出初代对基于拥有一定入伍时间，形成了服从命令的肌肉记忆的老兵强制标准化限制锚。该个体在经历多次实验后无法维持正常人格，故留在研发部注册成为公司资产，作为肉畜受试体榨取剩余价值。

# 批注

## 战斗模拟

对该个体注射肾上腺素，观察其对普通藏品、安保部常规藏品、安保部公关部门藏品的战斗应对。该个体在对上安保部门部长 No.4 时，出现了精神崩溃、抗拒战斗、无法控制肢体的反应。

==实验表明我司近期合成的对人类特化的恐惧类吸入激素具有一定的效果，但是需要进行持续吸入，藏品需对被攻击对象进行精神折磨才可进一步生效。==

在战斗模拟中，我司藏品在逐步解放限制中，成功激起了狩猎欲望，通过预设的战斗编码能达到一定的战斗水平，但仍不足以与经验丰富的军人进行无伤捕获，No.4 在该个体崩溃后产生极大兴趣并对其进行了强制配种，实验人员只好暂停实验并在该个体被同化吞食前，将其体内的黑胶强制排出。

## 同化肉体抵抗测试

对该个体注射实验药物“原始黑胶抗体”、注射从黑胶匹配度低的个体身上提取的生物质、注射猛兽种通用抗过敏药。观察其面对 9-3 级权限藏品的黑胶注入时的同化速度，在其四肢全部耗尽后停止试验。

经观察，该个体抵抗黑胶同化的速度与其他受试体并无太大区别，今后我司将继续研究黑胶匹配度低的个体。

## 强制洗脑抗性测试

该个体对强制洗脑产生了极大的抗拒，跟黑胶匹配度低的个体相同，该个体难以通过行政部的常规调教洗脑成为我司成员，但是用军队的模式对其进行暗示催眠时，该个体产生了极大的服从进步，这对于我司收复入伍肉货的研究具有重大意义。此实验结束后，该个体难以继续进行后续实验，对黑胶同化的抵抗度降低到了最低，已无法维持基本人格。
