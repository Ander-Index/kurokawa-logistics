# 报告

公司调查清楚后对此进行介入，在该个体意图与他人建立联系之前进行强制绑架， 利用其情绪漏洞进行忠诚度洗脑，投入遗迹车床中进行半执行体化，随后作为研发部的黑胶研究科成员投入使用。

# 批注

作为黑胶研究科的研究成员，必须具备能操控黑胶的能力，自主研究的智力和人格，以及在长时间暴露在原始胶原中的免疫能力，因此对该个体进行全黑胶包裹的半执行体化，以永久阻挡胶原暴露对肉体产生的损害。该个体的健康情况将会作为今后该科室员工改造的参考。
