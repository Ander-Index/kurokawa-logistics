# 报告

铭威，蓝色硬鳞龙，幼年时从国外移居的健身教练，无特殊背景，与 [[No.7-1-28-3]] 为竹马关系。 728 从家中跑出并在雪天遇难时，被路过的我司成员捡到入职，从此铭威就一直在寻找失踪的 728 ，最终追到 728 的任务所在地，打砸并破坏了我司的财产并协助肉畜逃跑，被当地分基地成员发现捕获。

行政部按照规定将该个体制成了罪机，该罪机在服刑期间屡次反抗并突破限制，限制锚对其大脑进行了多次删改和调整，最后和 728 完成了最终的调整，彻底服从于我司。

该个体目前在原来工作的健身房继续生活，由于服刑期间多次被修改大脑，该个体已患上服从成瘾病，在经过说明后重新回到本部接受执行体化改造。
