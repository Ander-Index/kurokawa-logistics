# 报告

因其专业（物流管理）被建议改造为运输部部长。

改造后性格轻微残暴，富有侵略性，从事黑川物流的所有物流项目工作，和协助人事部进行收藏品雏形的收集运输，是黑川物流经济来源的核心。

开辟了收藏品外派展览业务，概率收回新的收藏品雏形，缓解了公司的财政压力和用人压力。

# 批注

该收藏品和 [[No.2]] 行政部部长存放在相同的展览柜时容易发生磕碰。

该藏品好动好战，建议进行打包展览处理来进行管教训练。
