# 报告

据该个体回忆：

有一天他收快递的时候，阳光开朗的黑川物流快递员大哥哥一眼就看出了愁眉苦脸的寒檀有难处，在了解了情况之后，遂即向其推荐了在黑川物流作一名快递员的工作。

在其偶尔在返回支部站点准备休息并装填快递车货舱的时候，撞见自己所在支部的部长正在被一只金虎捆绑，身上还不断地有黑色不明物质在其身上穿入穿出。

当时虽然他很害怕，但是好奇的性格却让他驻留原地。与此同时，他惊奇地发现自己竟然看的产生了性唤起。

很快他就被那只金虎发觉了他的存在，后来他才知道那正是他部门的王——No.3

No.3 发现他之后先是一愣，随后立刻甩出黑胶绳索将他拉到跟前，发觉自己似乎无法直接控制眼前的个体时才意识到这是一个并没有被植入锚的普通快递员。

出于保密的需要，No.3 不得不紧急请求人事部调取该个体的背景，并在对其植入了锚后进行了紧急教育。

<font size="6">附加报告</font>

根据系统日志记录，那时的 No.3 正在例行为各个物流支部的部长进行现场再教育，但由于疏忽大意，没有做好安保工作，致使增加了招聘计划外的职员。

No.AZ 已执行过对 No.3 进行惩罚。

执行方案为：捆绑束缚。

期限为：3 天。

# 批注

No.3 在执行分部部长执行的“回收支部部长以进行定期深度教育”的回收任务中，由于公司运营经验过浅，保密协议存在漏洞，导致被该个体在未入职的情况下以视觉的方式直接接触到了公司机密，在后续调查中，发现该个体实则为内部员工引荐，实则已经做好匹配度调查的藏品雏形，可以在进行工作视察后，直接对其进行入职手续。

No.3 尚不清楚这一点就对其进行强制打包，未做好入职引导工作，缺乏应变能力和警惕心。

建议将此次事件做成负面案例，纳入保密协议课程中供职员学习。
