# 报告

包装工程毕业的应届大学生，根据其专业性，该藏品雏形本该入职市场部。但是该藏品的入职意向为运输部运输科。据此，市场部与运输部部长的争执落下帷幕。市场部部长最终让步。据了解，其不愿意去市场部的原因是已经对求职市场心灰意冷，想要放下这件事情，也让自己休息一下。

受过良好的入职教育后的白塵在运输部也在发挥着自己的专长，是绑架科的手法大师。内部著作《翻花绳》就是这位工友的作品，时至今日也是 KKN 上实用工具榜阅读量前几的作品。

其设计的“材料与捆绑方式”结合的结果使打包速度提升的同时也增加了美观性。
