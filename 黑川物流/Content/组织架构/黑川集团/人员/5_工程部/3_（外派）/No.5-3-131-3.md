# 报告

在校本科生，于大三时为挣取外快和获得毕业实习学分，签署短期劳务合同入职。在体检中检测到了极高的黑胶胶原适配度，同时伴有内分泌失调，大脑混乱程度高等不健康情况。经心理咨询发现该个体具有强大的隐藏执念，人事部开会投票后决定对其进行强制入职。

经训练和教育后，该个体以极快的速度日以继夜地练习如何操控胶原，并多次试图违规注射和使用令自身强制清醒的药品/镇定锚，该个体按照人事部预想的那样，很快就掌握了大部分工程部的工作和部分运输部的知识。

该藏品在被 [[No.AZ-3-1-1]] 强制关机并治疗结束后主动要求调去其他城市建设后勤基地。根据能力评估，该藏品完全有能力胜任分队的小组长，故赋予其最终编号。该藏品在调去其他城市后，屡次申请进行人事部未派发的强制入职任务，为激励员工准予批准，该藏品独自潜入当地城市的某大学后带回一位C级子代，在这次行动的此后，该藏品的忠诚度评估提升到最高。

# 批注

为激励员工，上级可以准许一些超出原则的申请，但是要注意因私人恩怨等个人情感而发出的申请，即使准予通过也不能提供过多补助。

为保险起见，今后与该藏品类似行为入职的子代都应当默认登记为 C 级，给予最低级的权限。
