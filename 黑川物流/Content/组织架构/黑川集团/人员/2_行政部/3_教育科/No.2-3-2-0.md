# 报告

于至少 50± 年前意外闯入黑胶遗迹的兽人，后经过多个部门努力调查卷宗后确认为多年前失踪的民俗学家易朗，现在已判定为死亡结案。是由黑胶车床进行捕获洗脑改造后成为守卫遗迹的执行体，但因为设备年老失修导致洗脑没有完全执行，在 No.AZ 突破限制后被收编为所有物。

该执行体被安装了部分洗脑用器械，具有部分智能，在对其洗脑器械进行二次改造后将其作为行政部教育科的决策体使用，值得注意的是，该执行体残存的人格无法进行改造，在进行教育时依旧会对收藏品雏形进行目的为执行体化的强制交配和黑胶喷涂，在事态无法控制时请至少 2 位同级组长使用权限开启其限制锚进行打包修理。

在多个心理医生被其交配并涂满黑胶后，根据经验判定其人性和人格接近崩溃边缘，通过与生物进行交配来维持自身继续活着的欲望，出于关照，不建议通过对其强制洗脑来终止其对其他人执行体的行为。

# 批注

该执行体历时半年成功恢复部分理智，但是执行体化生物的本能与其人格已经牢固绑定，请无视其“调情 ＝ 打招呼”的行为。该执行体热衷于骚扰研发部同为执行体的 "[X](No.AZ-3-0-0.md)"，请研发部安保人员注意其行踪。
