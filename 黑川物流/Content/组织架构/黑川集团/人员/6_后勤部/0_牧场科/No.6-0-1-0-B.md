# 报告

个体名霍格，出生自和 No.AZ 研发部部长相同的小镇，作为当地民俗神的祭祀活动的主持者被培养，经民俗调查发现该小镇信仰的民俗神与黑胶科技遗迹制造的试作型执行体有着一定联系，为保证对遗迹的控制，AZ 对该个体进行邀请入职。

与 AZ 交涉后献上信仰，被活化的财政部沙发捕获强制同化，后送往行政部进行教育入职。因同化程序有差异而导致思维轻微执行体化，从而不作为公司不动产，而是作为后勤部的部长秘书入职，仅地位权限高于 2 的员工可使用该物化收藏品。

该个体作为半执行体具有一定的智能，可露出面部，无需喂食，可对自身进行自体保养。

# 批注

考虑到文化对该个体家乡的影响，是否要强制介入停止其民俗祭祀活动有待考量，请在其神社进行祭司活动时将该收藏品放归主持，放归任务中，至少有一名携带了未使用的常识修改锚的公司员工对其进行监视和回收，并时刻注意其他延续祭司活动的村民，必要时进行强制入职。
