# 设施简述

- 肉池是一个用于预处理肉货的肉胶设施，该地点是一个两层建筑，二楼的楼层地板和一楼的天花板由一层暗红色肉胶隔开，肉胶呈现半透明的状态，可以看到内部的支撑支撑框架和垂直打下的各个垂直打下的孔洞，肉池中能看到给肉胶提供营养的各种输送管道，和用于培育肉货的输送管道。

- 一楼的空间设计用于巡视天花板上面下垂的肉货情况，地面的空间用于运输肉货和产物，设有检测产品的隔间，通过货梯可到达二楼。二楼是投放肉货的区域，有数个矩形排列的点阵孔洞在地上的肉胶层中开出，天花板上有着监控用于监视还未完全下落的肉货，在此投入的肉货需要提前体检并消毒，有体检功能的基地可不在二楼设置体检功能区。

# 使用流程

>[!INFO] 本段落为肉货在正式投入生产前的改造流程示例，以供二次创造的参考。

1. 一名任意途径获得的人类，在经过审批后将会送往体检，若是合格则可投入肉池。
2. 肉货会被送到二楼清洗干净，在进行洗脑操作（可跳过）后直接投入孔洞中，孔洞中存在负压和触手，会将肉畜的下半身吞噬固定，并根据体型施加不同程度的压力和束缚。
3. 肉畜的身体将会被注入大量能提高身体敏感度和健康程度的毒素和营养，催化特定器官并加强其产物的产量，肉池将会对“生产”这一行为培育条件反射，在肉货每次生产的过程中提供正反馈，使得肉货逐渐放弃抵抗。
4. 肉货的双手将会被触手分别吸入，并在下落的过程中贴紧身子，形成一条饱满的能产出美味汁水的黑胶条茎。
5. 在肉货的全身都完全陷入肉池中后，肉池会对肉货进行最后的包裹改造，从神经到思想都完成“羽化”，期间一楼的天花板会垂下果实，后勤部员工可通过果实质量判断肉货的各项数据。
6. 彻底改造结束后，肉货的下半身将会露出一楼，以提供生产的稳定温度。
7. 后勤部员工经过一段时间的丰收后，将会用力将目标扯下，拆除可重复利用的洗脑部件或者是断裂的管道等，在生产部位上打上标识并登记上传，送往牧场用于生产食物和胶原。

# 设施功能

>[!INFO] 本段落为后勤部中，该设施具体可以做到的功能。

- 肉胶层可通过设定的程序自动分泌能够改造碳基生物的分泌物。
- 将投入二楼孔洞中的肉货逐步吸入狭窄的孔洞中，肉货会被肉胶中伸出的触手管道逐渐包裹各个肢体。
- 在化合物与黑胶衍生物对全身进行改造的过程中，肉货将会逐渐被孔洞吸入并被胶衣包裹。
- 肉货的产品将会顺着管道在一楼对应位置的天花板中结出一颗装满产品的果实，果实会下垂到能够轻易采摘的部位，以供后勤部员工验收。
- 后勤部员工可通过果实质量判断肉货的转化程度，若是合格则可以进行观察期预生产。
- 在观察期中，肉货大腿以下的部位将会下垂到一楼，表明该单位已基本成熟。若是产量稳定，则可以将肉货用力拔下，在喷涂条码登记后送往牧场投入生产。
- 使用了一定时间的肉货也可投入此区域进行保养，在使用多次后，可将肉货投入肉胶层中直接消耗并升级[[#设施等级]]。

# 设施创建要求

1. 有一定数量的后勤部员工。
2. 该基地中存在[[胶兽培训室|肉胶巢穴]]提供肉胶。
3. 该基地中存在[[后勤部#0 牧场科|牧场]]（肉池可储存肉货提供生产地点，但是此行为会消耗肉池使用寿命。）
4. 有体检部门。

（本部当然有肉池啦。）


# 设施等级

拥有以下条件可提升设施的等级，以提高设施效率

## 后勤部

### 中控

肉胶的基础设置需要一名擅长自主合成制定化合物的员工，提供对肉池持续性的监控和指挥，维持肉池作为湿件的使用寿命，以及内部肉货的生命体征。

### 数量

足够的工作人员能分担各环节的压力。

## 财政部

### 精细化处理

财政部可提供设施联网，可用各种途径提供对肉货点对点的精细化调教和改造，而不是使用肉池自带的缓慢封闭改造。包括但不限于：

1. 使用胶兽网络分配算力直接对肉货进行精细化调教
2. 将一名算力单位直接投入肉池，使肉池自备惊喜操作功能。
3. ……

## 行政部：

### 洗脑

行政部可提供洗脑配件或洗脑服务，加速肉货改造。

## 运输部

### 绑架科

绑架科可提供货源，避免孔洞空置。
