# 详细信息

<font style="background: black;color:rgba(0,0,0,0)">早就被 ID.ROOT 亲手改造成最大杀器了。</font> 

雨龙高中毕业后并没有按照父亲期望的那样在部队留下，而是远走异国他乡。回国后加入了当时还是初创公司的龙珀。

沉稳和精明是他展示给外界的平静“海面”，而其之下暗流涌动的则是曾经的他，冲动，倔强，温良，更深的是他自己都察觉不到的不安全感及其沿伸出的灼伤他人的占有欲。

父亲是一名少将，母亲在他11岁那年因一场“意外”离开了。雨龙自记事起便跟随军队一起训练，那时他就觉得身边的一切都是冰冷的，只有母亲的手是温暖的。母亲的离开成了他生命中的痛，而他将这份“怨恨”转移到了造成这场“意外”的父亲身上。成年后，他决定不走父亲给他铺设的道路。但血缘的纽带哪有那么容易断开呢？龙珀取得如今的成就，除了雨龙自身的努力，他父亲的身份地位也是不可或缺的。
