# 报告

前国家研究所研究员，由于不满意体制内的底层研究员令人窒息的低效率，主动离职。正巧遇见被龙珀科技开始招聘开发者，于是心安理得地加入，成为早期员工之一。

其帝国理工大学材料学博士毕业。一条蓝龙，身形修长，常戴着一副黑框眼睛，眼里写满了疲倦，墨绿色并带有亮绿挑染的头发正在在实验室中被快速消耗着，橘红色的眉毛在皱眉时会显得压迫感巨大，眼角的红黄色花纹为其增添了一抹神秘。

彼时的龙珀科技正研制售卖新的军火，昱江负责其中一款产品的研发。在产品发布之后，昱江终究扛不住兵不血刃的心理压力，企图退出。他希望凭借着自身在材料学研究方面的知识经验为他在一家更为民用的公司找到工作。

但是龙珀的高层一致认为，作为龙珀元老级的人物，可能已经知道了太多了内部机密，遂以更高的薪资与代价“邀请”其留在龙珀内部研发机械科技。

# 入职报告

“我们非常能理解您的心情，我们也不想失去您这个人才。所以我希望咱们可以合作的更进一步，相信你看了我们最为机密的产品，就能够继续为我们效劳。”

[ADM02](ID.ADMIN-2.md) 轻轻拍了拍手，旁边本没有任何缝隙的墙竟然移动并打开了一个门！

看着地下实验室中，培养皿里的白色粘稠液体在 ADM02 的简单手部动作的操控下变成各种冷兵器的形状。昱江骨子里那种属于研究员的好奇心被完全地激发了。

“太……太完美了……”

# 批注

由我司研发部门负责的新版洗脑服从程序和记忆管理芯片，现开始投入使用。

目标在覆盖薄层胶液后成功兵奴化，芯片成功将目标负责技术和记忆的脑部区域保留，表层毛皮腐蚀严重，已涂装轻量级装甲。

验成功，该科学家的自主思考能力以极低的损耗率成功通过测试，建议立即将我司所有研究人员兵奴化。
