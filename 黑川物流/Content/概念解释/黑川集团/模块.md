# 触手

所有员工的必备基础模块，将难以操纵的液态黑胶转化为肢体的技能

# 毒素分泌

基础模块之一，安装后能主动调整毒素的分泌，包括藏品自带的[[多态神经诱捕素]]分泌，以及下载模块后分泌的麻痹，镇静类毒素。

# 打包

下载后，能快速学会用各种工具打包各种体型的肉货。
坚固体甲

# 坚固体甲

安保部发行的模块。能将黑胶主动氧化为坚固的暗灰色装甲。

# 数据传输

基础模块之一，安装后能分泌出一根黑胶长舌，和员工之间进行高效率无损的的数据传输。

# 行走

为完全黑胶化的职员设计的模块。安装后能自主构建各种结构的肌肉，配合人工骨架实现快速移动。

# 全视

基础模块之一，使用需要天赋。安装后唤醒胶兽原本应有的”视觉“，获得对周边全景的感知。对声音，温度等的感知有额外模块可以进行下载。

# 空间压缩

安装该模块需要一定的黑胶规模。可在体内或者器具内压缩一定范围的空间，以装下更多的内容物。
